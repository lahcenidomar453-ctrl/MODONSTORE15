# MODONSTORE — نسخة ثابتة مناسبة للعرض والتجربة

## شنو فيها؟
- تصميم عصري ومتجاوب للهاتف والحاسوب.
- بحث وفئات وترتيب المنتجات.
- سلة مشتريات ومتابعة الكمية محفوظة داخل نفس المتصفح.
- زر واتساب برسالة جاهزة للاستفسار عن الطلب.
- لا تحتاج Node.js أو إعداد سيرفر: افتح `index.html` أو استعمل VS Code Live Server.

## النشر
يمكن رفع ملفات هذا المجلد إلى GitHub كمشروع للعرض والتطوير. **تنبيه مهم:** GitHub Pages لا يُسمح باستعماله كاستضافة مجانية لموقع هدفه الأساسي تسهيل المعاملات التجارية، وفق توثيق GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

## الحدود الحالية
هذه واجهة تجريبية وليست متجرًا تجاريًا متكاملًا: المنتجات أمثلة، ولا توجد قاعدة بيانات أو حسابات أو لوحة إدارة أو تسجيل مركزي للطلبات أو دفع إلكتروني أو تكامل شحن. السلة تحفظ محليًا في المتصفح فقط. زر واتساب يفتح رسالة للاستفسار ولا يؤكد الطلب تلقائيًا. لا تدخل معلومات حساسة في هذه النسخة.

لإطلاق متجر حقيقي، استعمل استضافة مناسبة للتجارة الإلكترونية مع Backend وقاعدة بيانات وخدمة أداء وشحن. يمكن إبقاء الكود في GitHub وربط النشر بخدمة استضافة مناسبة.
